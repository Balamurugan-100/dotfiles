Write a Git commit message for the staged changes.

Follow good Git style:

- Separate the subject from the body with a blank line.
- Capitalize the subject and use the imperative mood.
- Do not end the subject with punctuation.
- Keep the subject short and specific.
- Only include a body when it adds useful context; wrap it at 72 characters.
- Do not repeat information from the subject line in the body.
- Return only the commit message, without code fences or commentary.
